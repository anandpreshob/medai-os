## How to read this

"Verified" has one meaning here: **an automated test loads a named public fixture and asserts on the result.** Manual clicking is not recorded anywhere in the repo, so it does not count. Today only two rows meet that bar.

| Symbol | Meaning |
|---|---|
| ✅ | Automated test on a named fixture passes |
| 🟡 | Code path exists; no test; not known to be broken |
| 🔴 | Code path exists and is known broken, or explicitly simulated |
| ⚫ | No code path |
| P0/P1/P2 | Priority for Phase 1 (P0 = must be ✅ before Phase 2 starts) |

Fixture IDs refer to [03_SAMPLE_DATA_MANIFEST.md](03_SAMPLE_DATA_MANIFEST.md).

## E. What "done" looks like for Phase 1
